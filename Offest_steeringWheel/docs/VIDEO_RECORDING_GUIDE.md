# 仿真视频分阶段运动模式说明

## 录制前准备

1. 关闭所有旧launch，确认ROS图中只有一套控制节点。
2. 启动完整仿真、Qt目标位置控制台和独立曲线监测窗口。
3. 在第二个终端启动`teleop_twist_keyboard`。
4. 录屏画面同时包含MuJoCo、Qt目标位置控制台和曲线监测窗口；讲解曲线时将独立监测窗口置于前台。
5. 每次切换控制来源前先停车：键盘按`k`，或Qt点击“停止”。

## 两种位置模式的字幕模板

### 世界位置＋固定Yaw

```text
控制模式：世界坐标系目标位置 / 固定Yaw
目标：X = __ m，Y = __ m，Yaw = __ rad
控制行为：平移速度根据世界位置误差闭环生成，Yaw全程保持设定值
```

### 世界位置＋动态Yaw

```text
控制模式：世界坐标系目标位置 / 动态Yaw
目标：X = __ m，Y = __ m，最终Yaw = __ rad
控制行为：Yaw按位置完成进度平滑插值，与目标位置同步到达
```

## 曲线讲解要点

- 轨迹误差应整体下降并最终进入位置和Yaw容差。
- 舵角曲线反映每个偏置脚轮为满足全向运动进行的连续转向。
- 轮速曲线正负号表示各轮转动方向，幅值表示速度分配。
- 组合运动阶段舵角和轮速应同时变化，不应出现“先转向、后行驶”的长时间分离。
- 停止后轮速应快速回零，舵角可保持在停止瞬间的位置。
