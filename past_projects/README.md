# Past Robotics Projects

本目录收录李骏远在全国大学生机器人大赛 RoboCon 期间参与的两个代表项目，作为宇树科技“天才少年”项目申请的补充工程材料。

## 项目目录

### 排球机器人

- 工程目录：[volleyball_robot](volleyball_robot/)
- 比赛经历：第二十四届全国大学生机器人大赛 RoboCon 机器人排球挑战赛全国二等奖
- 个人角色：电控组组长
- 个人职责：可动机构运动控制算法与执行器驱动实现
- 当前材料：STM32F407 下位机、Python 视觉上位机、Modbus RTU 协议和主机侧测试

项目说明、接线、运行方式、调试步骤和验证边界见工程内的 [README](volleyball_robot/README.md)。

### 武林探秘 R2

- 工程目录：[wulin_exploration_r2](wulin_exploration_r2/)
- 比赛经历：第二十五届 RoboCon 武林探秘竞技赛全国三等奖，九宫藏宝与崇武探幽技能赛全国三等奖
- 个人角色：副队长兼电控组组长
- 个人职责：上下位机通信设计、可动机构运动控制、执行器驱动硬件与控制实现、里程计和 IMU 融合定位
- 当前材料：STM32H723 FreeRTOS 下位机、ROS 2 上位机、USB 协议、动作序列和功能核查

项目总览见工程内的 [README](wulin_exploration_r2/README.md)，当前上下位机功能、已接通流程和真机验证边界见 [上下位机功能核查](wulin_exploration_r2/上下位机功能核查.md)。

## 验证口径

本目录保存的是当前整理版工程。文档中的“已实现”表示当前源码存在可追踪的执行路径并完成相应主机侧检查，不代表所有整理后的功能都曾在比赛期间使用，也不代表已经重新完成完整固件编译和真机联调。比赛成绩和个人职责以证书、队伍记录及现场材料为准。

2026 年 9 月 13 日复核结果：

- 排球机器人 Python 上位机 7 项单元测试通过；下位机 Modbus CRC 与解析、Delta 状态、机构互斥与看门狗、运动学与底盘矩阵主机测试通过。
- 武林探秘 R2 控制计划一致性校验通过；PC USB 串口工具 21 项协议测试通过。
- 当前复核环境未安装 ROS 2 Humble，未重新运行 `colcon build` 和 `colcon test`；当前也没有连接真机串口和执行机构。

工程包含 STM32 HAL、CMSIS、FreeRTOS、Ultralytics YOLO 权重及其他第三方组件。使用或再分发时应分别遵守各组件的原始许可。当前整理材料不能替代对所有第三方文件的逐项许可核查。
