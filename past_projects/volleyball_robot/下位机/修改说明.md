# 下位机修改说明

本目录是排球机器人整合版 STM32F407 工程。主要变更如下：

- USART1（PA9/PA10）改为 Modbus RTU 从站，地址 1、115200、8N1。
- UART4 遥控器初始化、接收中断、遥控量叠加和控制权切换已停用。
- CAN1 的 1/2/3 号 3508 用于底盘，4/5/6 号 3508 用于 Delta。
- 新增底盘定速和绝对定位、Delta 击球/回原位、CyberGear 甩杆预备/回原位/击球状态机。
- Delta 与甩杆动作互斥；通信中断和电机反馈丢失进入安全处理。
- Delta PID 为 `25 / 0.05 / 0.2`，输出上限 12000，积分上限 3000。

完整接口、接线、机械零位和实机调试步骤见上一级 `README.md`，寄存器表见 `docs/modbus_registers.md`。
