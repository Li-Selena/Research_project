# 机器人统一坐标系

本文是项目中坐标、方向和协议字段语义的唯一总约定。固件状态协议从版本 `4` 起采用本约定。

## 1. 整车与世界坐标系

机器人本体坐标系采用右手系：

- `+X`：车头向前
- `+Y`：车体左侧
- `+Z`：竖直向上
- `+yaw` / `+wz`：从上方观察逆时针

底盘原点位于几何中心。世界坐标系在 `yaw=0` 时与本体坐标系重合，世界 `+X/+Y/+Z` 的方向随后保持固定。机器人系速度或位移转换到世界系时，使用当前 yaw 绕 `+Z` 旋转。

## 2. 接口字段

| 接口 | 第 1 轴 | 第 2 轴 | 旋转 |
|---|---|---|---|
| `CHS_SET_VEL` | `f0=vx`，向前为正 | `f1=vy`，向左为正 | `f2=vw`，逆时针为正；无 yaw 模式下为锁定角 |
| `CHS_SET_POS` | `f0=dx`，向前为正 | `f1=dy`，向左为正 | `f2=dyaw`，逆时针为正；无 yaw 模式下为锁定角 |
| USART 遥控帧 | `float0=vx/dx`，向前为正 | `float1=vy/dy`，向左为正 | `float2=vw/dyaw`，逆时针为正 |
| 底盘状态 | `x/vx/err_x`，向前轴 | `y/vy/err_y`，向左轴 | `yaw/wz/err_yaw`，逆时针为正 |
| 机械臂目标 | `x` 向前 | `y` 向左 | `z` 向上 |

机器人系和世界系模式使用相同轴正方向，差别只在于轴是否随车体 yaw 转动。

## 3. 机械臂、IMU、轮组和传感器

- 机械臂目标以机械臂基座为原点，轴方向仍为 X 前、Y 左、Z 上，单位为毫米。
- HWT605 安装后的原始传感器轴为 X 右、Y 前、Z 上。`INS_Task` 在数据进入导航与控制前只转换一次：`robot_x=sensor_y`、`robot_y=-sensor_x`、`robot_z=sensor_z`。原始调试字段必须明确标注 `sensor/raw`。
- 麦轮名称 `FL/FR/BL/BR` 表示物理左前、右前、左后、右后。运动学输出的轮速以轮子使车辆向前滚动为正；右侧电机安装反向只在 CAN/编码器边界处理。
- 攀爬小驱动轮目标为正表示整车向前。立杆位置 `0 mm` 是上电接地点，正值向下伸出并抬升车体，负值向上收回，范围 `-30..260 mm`。
- 激光字段 `x_pos`、`y_pos` 是接线通道名和距离值，不表示带符号的里程计 X/Y 坐标，坐标迁移不交换这两个通道。

## 4. 从旧底盘坐标迁移

旧底盘约定是 X 向右、Y 向前。保持实际运动方向不变时：

```text
new_x =  old_y
new_y = -old_x
new_yaw = old_yaw
```

该关系适用于底盘速度、位移、里程计和自动标定轨迹。机械臂有效控制接口此前已经采用 X 前、Y 左、Z 上，因此机械臂目标值不再旋转一次。

## 5. 文件和单位

- 文本源文件统一使用 UTF-8 和 LF。
- 线位移：底盘用米，攀爬机构和机械臂用毫米。
- 线速度：底盘用米每秒；角度接口按各字段注明使用度或弧度。
- 代码中的局部二维连杆坐标可继续使用 `x/y`，但注释必须说明它不是整车坐标。
